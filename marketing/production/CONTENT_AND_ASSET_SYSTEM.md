# Content and Asset System

## Copy assembly

Build copy in this order:

1. **Approved identity:** correct Just One KISS name and independent-tribute posture.
2. **Family headline:** one emotional argument, normally four to nine words.
3. **Sensory/proof line:** one observable image or credible benefit.
4. **Fact overlay:** only facts necessary for this audience and placement.
5. **Action:** one verb and destination that fulfill each other.
6. **Required microcopy:** disclaimer, advisory, consent, availability, or terms.

Draft patterns are prompts, not approved copy: contrast (“A ___, not a ___”), transformation (“From ___ to ___”), arrival (“The ___ arrives/answers”), command (“Open/Join/Enter ___”), devotion (“A love letter with ___”), and poster stacks (date / offer / venue / place).

## Copy matrix

| Mode | Sentence behavior | May be theatrical? | Must be literal? |
| --- | --- | --- | --- |
| Hero | Short, declarative, memorable | Yes | Identity and any fact |
| Spectacle | Sensory, specific | Yes | Actual effects/capabilities |
| Community | Warm, inclusive, useful | Yes | Value exchange and permissions |
| Utility | Short complete sentences | Minimally | Dates, access, directions, parking, camping |
| Consent/privacy | Plain and explicit | No | Collection, purpose, action |
| Safety | Calm and visible | No | Hazard/advisory meaning |
| Disclaimer | Canonical and consistent | No | Independence/legal meaning |
| Buyer/press | Confident and evidence-led | Moderately | Capabilities, availability, contact |

## Asset record minimum

Stable ID; title; type; description; campaign/stage/family; timeline classification (`GEN` unless tied to an actual cue); source/creator; ownership; releases/permissions; recognizable people; marks/protected design risk; generation/edit history; fact-bearing text; alt text; safety/effect implications; allowed channels/regions/term; prohibited uses; review statuses; master dimensions; derivatives; checksum; storage path; owner; expiry; supersession.

## Still-image production rule

Generate or photograph the atmosphere **without final small text whenever possible**. Add exact headline, facts, disclaimers, and CTA as controlled typography in the design file. Never rely on generated lettering for critical facts. Preserve dark copy zones and crop safety in the source composition.

## Motion production rule

Storyboard the reveal, captions, fact hold, CTA hold, audio rights, flashing-pattern behavior, poster frame, thumbnails, and sound-off experience before editing. Intensity should come from staging and contrast, not unsafe or unreadable speed.

## Fan media

Before reuse, capture submitter identity/contact, asset, date, ownership assertion, subjects/minors considerations, requested credit, permission scope, allowed channels, edit rights, paid advertising permission, merchandise permission, term/territory, revocation route, moderation decision, and evidence. When scope is unclear, do not publish.

## Accessibility package per piece

- alt text or explicit decorative status;
- captions/transcript for motion/audio;
- text contrast and minimum readable size review;
- reading order and keyboard/focus behavior for web;
- no critical fact conveyed only by color/image/audio;
- reduced-motion/static equivalent where relevant;
- descriptive link/CTA;
- readable duration for on-screen facts;
- plain-language warning/consent treatment.

## Deliverable package

Keep editable master, linked source assets, fonts/licenses, copy sheet, export map, actual exports, alt/caption files, rights evidence, review notes, release record, and checksum manifest together. A flattened image alone is not a reusable campaign asset.
