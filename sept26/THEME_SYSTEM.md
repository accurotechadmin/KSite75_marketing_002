# September 26 Theme System

**Purpose:** support two legitimate creative modes without confusing a fresh theme with a change to brand truth.

## Declare the mode before concepting

Every brief must select one:

- **Mode A — Current-theme fidelity:** reproduce or extend the established black/chrome/fire theatrical world.
- **Mode B — New-theme exploration:** create a fresh campaign expression while preserving brand, factual, legal, rights, safety, accessibility, and conversion invariants.
- **Mode C — Controlled hybrid:** preserve specified current signatures while introducing a named new organizing idea.

If the user has not selected a mode, ask. Do not treat “make it fresh” as permission to discard identity, and do not treat “on brand” as a demand to copy a prior layout.

## Fixed versus variable

### Fixed in every mode

- Just One KISS name and independent theatrical-rock tribute posture.
- Verified event facts only.
- No implied official affiliation, sponsorship, authorization, or endorsement.
- Original/cleared asset requirement.
- Plain safety, access, consent, privacy, terms, and disclaimer meaning.
- One dominant message and one primary action.
- Accessible critical text, contrast, captions, alt text, non-color cues, and appropriate motion treatment.
- Destination congruence, tracking discipline, review, release, and expiry controls.

### Variable with an approved brief

- Palette proportions and optional accent palette.
- Typography selection, if licensed and still legible.
- Composition grammar, materials, texture, illustration/photo balance.
- Headline metaphor and campaign-world vocabulary.
- Editing rhythm, sound design, motion language, and reveal structure.
- Campaign-specific logo/lockup treatment that does not create false official cues.

## Mode A — current-theme fidelity

Study before designing:

1. Canon §§4–6.
2. `../marketing/canon/BRAND_CANON.md` and `CAMPAIGN_CANON.md`.
3. `../proto/docs/currsite_visual_engineering_report.md`.
4. Representative `../currsite/` screenshots for the applicable page/section.
5. `../proto/public/assets/css/site.css` and approved candidate image families.

Match the **system**, not screenshot pixels: black stage depth, bone-white hierarchy, chrome structure, concentrated red/orange heat, signal-yellow facts, one monumental center, readable utility, poster-scale type, road-case/truss/haze material cues, and the tension between spectacle and practical hospitality.

Document which signatures are matched and which are intentionally changed. Do not replicate protected third-party expression or use a repository image merely because it visually fits.

## Mode B — new-theme exploration

A new theme needs a short theme charter before any final production:

1. **Strategic reason:** what audience problem does the new expression solve better?
2. **Core concept:** one sentence describing the world and emotional movement.
3. **Continuity anchors:** at least three recognizable Just One KISS invariants.
4. **Visual grammar:** palette roles, typography roles, materials, image style, composition, motion.
5. **Voice grammar:** headline rhythm, vocabulary, proof style, CTA treatment.
6. **Distinctiveness test:** why it cannot advertise any generic rock event.
7. **Rights/originality test:** how it avoids official-looking or derivative protected expression.
8. **Accessibility plan:** contrast, type, motion, captions, cognitive load, static alternative.
9. **Adaptation proof:** rough 9:16, 4:5, 1:1, and 1.91:1 compositions before polishing.
10. **Approval decision:** explore, revise, approve for this campaign, or reject/archive.

A new theme is a **campaign overlay**, not an automatic rewrite of evergreen brand canon. Performance may inform a later canon review but cannot silently change it.

## Mode C — controlled hybrid

Name the preserved anchors and the experimental layer explicitly. Example structure:

```text
Preserve: black-first stage depth, signal-yellow fact language, monumental central silhouette.
Explore: documentary grain, hand-printed utility type, colder silver/blue secondary light.
Do not change: identity, independence, verified facts, CTA clarity, accessibility controls.
```

## Theme evaluation scorecard

Score 0–2; require at least 20/24 and no zero in identity, distinctiveness, facts, action, rights, or accessibility.

| Criterion | Question |
| --- | --- |
| Identity | Is this unmistakably Just One KISS without looking official? |
| Strategic fit | Does it solve the stated audience/funnel problem? |
| Distinctiveness | Could it advertise any generic event? |
| Emotional movement | Is the intended before/after belief visible? |
| Hierarchy | Is there one center, one message, one action? |
| Fact integrity | Are volatile statements sourced and readable? |
| Action/destination | Does the action match what happens next? |
| Originality/rights | Is the expression original and cleared? |
| Accessibility | Does every adaptation remain perceivable and understandable? |
| Adaptability | Does it work natively across required ratios/durations? |
| Production realism | Can the source package support the idea pristinely? |
| Campaign coherence | Can multiple pieces vary without fragmenting the theme? |
