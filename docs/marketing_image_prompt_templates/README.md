# Adaptable Marketing Image Prompt Templates

These original templates form a reusable still-image campaign system. They are inspired by the repository's existing funnel structure and cross-platform production planning, but they contain no project-specific names, dates, locations, headlines, calls to action, facts, styles, or classifications.

## How to use this library

1. Start with `00_shared_template_contract.md` and choose or write values for every relevant bracketed field.
2. Select a stage template:
   - `01_awareness_prompt_template.md`
   - `02_interest_prompt_template.md`
   - `03_consideration_prompt_template.md`
   - `04_conversion_prompt_template.md`
   - `05_retention_nurture_prompt_template.md`
3. Keep the platform placement, dimensions, aspect ratio, and crop behavior defined in the chosen template.
4. Replace each bracketed field with one listed option or an original value.
5. Verify all public facts, claims, permissions, safety notices, legal language, platform specifications, destination URLs, and consent/privacy wording before generating, publishing, printing, or purchasing media.

## Bracket convention

A bracketed field is intentionally editable:

`[option one, option two, option three, write your own]`

The options are examples, not locked language. A field may also request factual input:

`[verified date or date range]`

Do not leave unresolved brackets in final production copy unless the brackets are intentionally part of the design.

## Files and roles

| File | Role |
| --- | --- |
| `00_shared_template_contract.md` | Shared inputs, export families, safe zones, guardrails, and output requirements. |
| `01_awareness_prompt_template.md` | Introduce a project, event, offer, cause, product, service, or announcement. |
| `02_interest_prompt_template.md` | Build desire by demonstrating mood, value, experience, benefits, or differentiators. |
| `03_consideration_prompt_template.md` | Present practical details, comparisons, logistics, eligibility, or decision support. |
| `04_conversion_prompt_template.md` | Encourage a verified next action without inventing urgency, scarcity, price, or availability. |
| `05_retention_nurture_prompt_template.md` | Encourage return visits, sharing, onboarding, community participation, support, or continued use. |

## Non-negotiable production posture

The creative choices are adaptable. Safety, rights, legal, privacy, consent, accessibility, and factual-verification duties are not optional when relevant. Parameterize the subject of those checks, but do not remove the checks themselves.
