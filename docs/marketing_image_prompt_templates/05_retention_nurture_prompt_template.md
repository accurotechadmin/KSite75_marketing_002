## 4. Art direction

Create an inviting return path that feels connected to the campaign but offers fresh value.

- Visual style: `[resource library, open toolkit, community grid, account dashboard, collection/vault, welcome-back editorial, milestone card, custom]`
- Layout: `[central container with modules, six-card grid, carousel sequence, vertical resource drawer, hero plus return paths, custom]`

- Type treatment: `[large welcome headline, concise module labels, progress or milestone only when accurate, compact CTA, custom]`

The visual should offer a clear reason to return. Avoid merely repeating the original announcement without new utility or context.

## 5. Composition notes

- Use `[3, 4, 5, 6, custom]` modules or return paths.
- Keep the project/brand and current context visible so reshared assets remain understandable.
- Separate community/share actions from support, account, or transaction actions.
- Use user-generated content only with appropriate permission and review.
- If showing progress, streaks, membership levels, points, rewards, or milestones, use accurate account-derived data or a clearly labeled generic illustration.
- Include communication-preference or unsubscribe context where required for promotional messaging.
- Avoid manipulative guilt, false loss, fake activity notifications, or manufactured social proof.

## 7. Guardrails and verification

- Verify membership, account, purchase, attendance, subscription, renewal, incentive, referral, points, rewards, and eligibility status before personalizing.
- Do not expose private account information or infer sensitive traits.
- Use consented communication channels and provide required preference/unsubscribe controls.
- State incentive, referral, giveaway, loyalty, review, and renewal terms accurately.
- Do not fabricate testimonials, community size, activity, popularity, reviews, countdowns, or scarcity.
- Obtain permission for user-generated content, names, handles, photos, and quotes.
- Apply relevant media/privacy, accessibility, safety, legal, and platform-policy reviews.
- Reconfirm platform dimensions and destination URLs before publication.
