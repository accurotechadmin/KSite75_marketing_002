# Just One KISS - Working Cue and Setlist Draft

**Purpose:** Capture the current working show-flow notes, set blocks, song candidates, transition notes, and cue implications that must feed the Timeline Moment Registry, Cue Bible, show-control run sheets, website/media planning, and rehearsal documents.

**Status:** Working draft / not final approved setlist.

**Timeline classification:** Timeline-specific. Each set block, song, transition, costume-change note, platform-drop note, and screen-drop note should be migrated into `docs/timeline_moment_registry.md` with a Timeline Moment ID before it is treated as show-ready.

**Source note:** This file began as the newest raw cue note in the repository. It has been normalized into the same base Markdown format as the other planning documents while preserving the original sequence, titles, durations, and parenthetical cue notes.

**Content / public-presentation note:** Song titles, album/era labels, and KISS-adjacent references are internal planning references. Public-facing use requires content review, performance clearance review, and public-ready copy review before publication.

---

## 1. How This Document Should Be Used

Use this file as the current working source for the tentative show-flow draft, not as the final cue bible.

| Use case | Required next step |
|---|---|
| Timeline planning | Convert each set block into a `SET-###` row and each song into a `SONG-###` row in the Timeline Moment Registry. |
| Cue programming | Convert parenthetical notes such as platform drop, costume change, and screen drop into `TRN-###`, `CST-###`, `VID-###`, `LGT-###`, `FOG-###`, or `STR-###` cue rows as needed. |
| Show-control run sheets | Add performer action, show-control action, trigger condition, fallback state, and emergency recovery path for each cue. |
| Rehearsal | Confirm actual durations, transition lengths, costume-change feasibility, screen timing, and streamlined show-control load. |
| Website / marketing | Treat the full draft as internal. Only publish reviewed, cleared, audience-facing excerpts. |

## 5. Timing Summary

Known listed durations total approximately **1 hour, 57 minutes, and 59 seconds** when `Let Me Go, Rock 'n' Roll` uses the 2:50 timing, or **1 hour, 59 minutes, and 3 seconds** when it uses the 3:54 alternate. This excludes the missing duration for `God Gave Rock 'n' Roll to You`, any transitions not represented by listed durations, applause, spoken moments, safety holds, costume-change overruns, and post-show activity.

| Timing issue | Required action |
|---|---|
| `Let Me Go, Rock 'n' Roll` has two possible durations. | Choose the performance arrangement and update the Timeline Moment Registry. |
| `God Gave Rock 'n' Roll to You` has no duration listed. | Add duration after arrangement is confirmed. |
| Costume-change and screen/platform cues may require additional safety time. | Validate in rehearsal with the approved live-production model. |
| Total show length may exceed practical booking limits once transitions are added. | Build a full run-time calculator in the future Cue Bible or Set Architecture document. |
