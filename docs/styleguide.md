# KISS Style Guide for a Tribute Landing Page System

This guide defines the visual, tonal, and structural direction for a Gene Simmons–inspired theatrical tribute event near Interlochen, Michigan on July 25, 2026. It supports the main landing page, paid and organic spoke pages, campaign creative, and related presentation materials.

The system must feel unmistakably rooted in classic KISS energy without becoming a generic rock flyer. The creative direction is black, chrome, fire, theatrical scale, fan mythology, and disciplined excess.

## Core Style Principle

KISS style is not simply a rock aesthetic. It is a recognition system built from repeated, highly legible elements: the all-caps lightning-bolt wordmark, comic-book personas, black-and-white face iconography, armor-like costumes, chrome, studs, platform boots, pyrotechnics, smoke, blood, tongue imagery, risers, and arena-scale spectacle.

The event presentation should not feel quiet, tasteful, or restrained. It should feel loud, staged, dangerous, theatrical, and larger than the room.

For a Gene Simmons–centered tribute, the dominant lane is the Demon: menace, bat-wing geometry, predatory posture, tongue-forward attitude, black armor, blood-red accents, fire, smoke, and mythic excess. The design should feel like a one-night arena ritual, not a standard concert listing.

## Presentation Foundation

The visual system should combine three primary KISS modes:

1. Alive! energy: live-show urgency, crowd heat, flame, volume, and movement.
2. Destroyer scale: fantasy apocalypse, ruined-city grandeur, mythic posture, fire-lit drama.
3. Demon identity: black, red, chrome, shadow, tongue, wings, armor, blood, and theatrical threat.

This combination gives the campaign its strongest center of gravity: live, mythic, dangerous, and unmistakably Simmons-adjacent.

Dressed to Kill can inform story and backstory pages through black-and-white photography, city grit, suits, and origin-story swagger. Love Gun can inform fan-facing and collector-style pages through fantasy-poster composition, saturated color, and classic-era maximalism.

The key rule is modularity. The page does not need every KISS cue at once. A black field, chrome framing, fire-red accents, a mythic central figure, and a loud display mark are enough to create the right signal. Add era-specific references only where they strengthen the page’s purpose.

## Color System

Black must dominate. The campaign should not rely on white-space minimalism, soft lifestyle tones, or muted boutique palettes. The colors should behave like stage lighting, screenprint ink, fire, metal, and poster graphics.

| Color Family    |       Hex | Meaning                                        | Use                                           |
| --------------- | --------: | ---------------------------------------------- | --------------------------------------------- |
| Stage Black     | `#050505` | Void, leather, stage depth, negative space     | Backgrounds, hero sections, section breaks    |
| Bone White      | `#F2F2EE` | Face-paint contrast, spotlight clarity         | Text, graphic contrast, mask-inspired shapes  |
| Chrome Silver   | `#B8BCC2` | Studs, armor, metal, stage hardware            | Borders, bevels, UI frames, dividers          |
| Blood Red       | `#B20D18` | Demon energy, danger, aggression               | CTAs, badges, urgent highlights               |
| Fire Orange     | `#F06A21` | Pyro, heat, motion, molten light               | Gradients, hovers, trailer/video areas        |
| KISS Gold       | `#D8A31A` | Classic grandeur, merch warmth, premium weight | Headline accents, VIP-style elements          |
| Electric Yellow | `#F2C230` | High visibility, concert-poster pop            | Countdowns, callouts, glow effects            |
| Cosmic Purple   | `#6D3FA9` | Fantasy, glam, night-sky atmosphere            | Secondary pages, transitions, featured-era flavor |

Use gradients only when they feel like fire, chrome, neon, spotlight, smoke, or comic-book sky. Avoid soft pastel gradients and modern SaaS-style color blends.

## Typography

Treat the cleared KISS-style display face as ceremonial headline type. It should appear in moments that need maximum impact: hero headlines, page titles, section openers, badges, and campaign lockups.

Do not use display type for long body copy. The system needs contrast between spectacle and readability.

Use three type roles:

| Type Role    | Direction                                       | Use                                          |
| ------------ | ----------------------------------------------- | -------------------------------------------- |
| Display      | Cleared KISS-style or sharp heavy display face | Hero headlines, lockups, badges              |
| Poster Sans  | Heavy condensed sans                            | Subheads, section titles, calls to action    |
| Utility Sans | Clean readable sans                             | Body copy, FAQs, details, ticket information |

The typographic feel should be concert-poster first, website second. Large type, compressed spacing, sharp hierarchy, and high-contrast blocks are preferred.

## Layout Rules

The layout must feel staged, not templated.

Use black as the dominant field. Build the page in dramatic sections that feel like entrances, reveals, and payoffs. Avoid delicate spacing and airy brochure layouts. Every major section should have a sense of impact.

Core rules:

| Rule                    | Application                                                          |
| ----------------------- | -------------------------------------------------------------------- |
| Black first             | Most key sections should sit on black or near-black backgrounds      |
| Chrome second           | Use silver lines, frames, bevels, or hardware-like dividers          |
| Fire third              | Use red, orange, and yellow as heat accents, not decoration          |
| One hero figure         | Anchor the page with a central theatrical presence                   |
| Oversize the moments    | Headlines, badges, countdowns, and CTAs should feel event-scale      |
| Keep the motion implied | Smoke, flame, spotlight, glow, and shadow should suggest performance |
| Never go ordinary       | Avoid generic venue, arts-center, or local-band flyer language       |

The site should feel like the digital front door to a spectacle.

## Page System

### Main Landing Page

The main page should carry the full Alive! / Destroyer / Demon blend.

Use a black hero section, colossal show presentation, chrome framing, fire and smoke motion, and a central figure or silhouette. The page should immediately communicate that this is a theatrical tribute, not a casual cover show.

Primary message: one night, high voltage, full spectacle.

Best elements:

| Element       | Direction                                              |
| ------------- | ------------------------------------------------------ |
| Hero          | Black, fire, chrome, central figure, large event title |
| CTA           | Red or gold, high contrast, direct language            |
| Countdown     | Electric yellow or fire orange                         |
| Video/trailer | Framed like a live transmission                        |
| Social proof  | Fan-language, crowd-language, event-language           |
| Ticket block  | Urgent, simple, unavoidable                            |

### Ticket Page

The ticket page should be the hottest and most direct page in the system.

Use fire colors, black backgrounds, bold pricing blocks, and minimal friction. The copy should sell urgency, scarcity, and event status.

Tone: get in, claim the night, do not miss it.

### Gene / Demon-Focused Page

This page should lean hardest into menace and theatrical identity.

Use black, blood red, chrome, shadow, bat-wing geometry, fang-adjacent forms, and ritual spotlighting. The copy should emphasize performance, transformation, fire, blood, spectacle, and the Demon lane.

Tone: darker, heavier, more mythic.

### Story / About Page

This page should use the Dressed to Kill lane.

Use black-and-white imagery, city grit, suit-like sharpness, origin-story rhythm, and confident editorial copy. This is the right place to explain the event concept without making it feel like a report.

Tone: swagger, origin, mythology, credibility.

### Video / Trailer Page

This page should use the Alive! lane.

Build around movement, crowd heat, lights, smoke, and live-show payoff. The page should make viewers feel the show before they buy.

Tone: loud, immediate, physical.

### Fan / Email Capture Page

This page should use fan-community logic.

The language should feel like mobilization rather than subscription. Use rally language, insider framing, badges, patches, and collector-style elements.

Tone: join the night, rally the faithful, get first access.

## Stage Language

KISS stage language is sensory overstatement. Fire-breathing, blood-spitting, smoke, risers, smoking guitars, loud entrances, custom stage environments, and giant visual payoffs are part of the emotional contract.

The landing page must translate that contract into web form.

Use:

| Stage Cue  | Web Translation                                   |
| ---------- | ------------------------------------------------- |
| Fire       | CTA heat, hero glow, animated accents             |
| Smoke      | Section transitions, background atmosphere        |
| Risers     | Layered hero composition, elevated central figure |
| Spotlights | Radial lighting, focused content reveals          |
| Explosions | Big section breaks, impact graphics               |
| Crowd heat | Testimonials, fan lines, video energy             |
| Armor      | Chrome frames, beveled cards, metallic dividers   |

The show should feel larger than the venue. Every major section should create a payoff.

## Fan-Culture Voice

The campaign voice should be direct, rallying, and theatrical. It should sound like an event calling people in, not a venue describing programming.

Use words with classic KISS emotional weight:

alive, louder, hotter, destroyer, thunder, army, night, shock, fire, blood, spectacle, legend, city, demon, chrome, stage, ignition, roar, command, unleash, rise.

Avoid refined, academic, apologetic, or overly explanatory language.

Do not write:

“This tribute experience seeks to honor the legacy of...”

Write:

“One night. Full fire. The Demon rises near Interlochen.”

Do not write:

“Fans may enjoy this theatrical interpretation.”

Write:

“Built for the faithful. Loud enough for the legends.”

## Copy Rules

The copy should be declarative. Avoid hedging, over-explaining, or sounding like a proposal.

| Weak                                               | Strong                                                         |
| -------------------------------------------------- | -------------------------------------------------------------- |
| This page should probably emphasize concert energy | Lead with concert energy                                       |
| The design might reference the Demon persona       | Build the page around the Demon lane                           |
| Fans may recognize these elements                  | Fans recognize black, chrome, fire, and mythic scale instantly |
| This could be used for ticket urgency              | Use this section to drive ticket urgency                       |
| The campaign should attempt to feel authentic      | The campaign must feel authentic, excessive, and staged        |

Write in short, forceful lines when selling the event. Use longer copy only for story and context.

## Presentation Independence Standard

The public-facing system should feel inspired by the KISS universe while maintaining its own original event identity.

Use the grammar: black, chrome, fire, armor, comic-book scale, fan mobilization, spectacle, and Demon-adjacent theatricality.

Create original lockups, original icons, original page compositions, and original campaign names. The design should evoke the emotional world without relying on direct duplication as the main creative move.

This is a creative discipline, not a limitation. The strongest tribute presentation feels familiar to fans while still owning its own stage.

## Final Creative Directive

Black first. Chrome second. Fire third. Mythic scale always. Ordinary never.

The website must sell a singular spectacle, not just a performance date. It should feel like the gates opening before the show: dark, loud, theatrical, and already in motion.

Every page should make one thing clear:

This is not background entertainment.
This is a one-night rock ritual.
