# Just One KISS - First Mockup Marketing Image Spec Set

**Purpose:** Provide a filled, authoritative first mockup version of the reusable marketing image prompt templates. This set translates the generic templates in `docs/marketing_image_prompt_templates/` into a polished five-batch Just One KISS still-image advertising system.

**Creative premise:** The wild beast has been tamed and now wears a suit while smiling politely: still black, chrome, fire-lit, theatrical, and dangerous in silhouette, but presented through a sleek professional event-campaign system with disciplined typography, clean information hierarchy, polished editorial restraint, and venue-buyer confidence.

**Status:** First mockup specification set / production planning data.

**Timeline classification:** `GEN` / GENERAL / NOT TIMELINE-SPECIFIC. These assets promote the event ecosystem as a whole, not one precise show cue.

## How to use this set

Start with `HOW_TO_USE.md` if you want a practical step-by-step workflow, prompt assembly recipe, designer brief recipe, asset-record checklist, and review gates.

1. Treat `00_shared_mockup_data.md` as the campaign-level variable sheet.
2. Use one stage spec at a time when creating design comps, image-generation prompts, or production tickets.
3. Keep the public facts, rights posture, safety posture, and no-paid-ticket language intact unless a later verified source changes them.
4. Reconfirm platform specs, destination URLs, form/privacy language, and final text before paid spend, publication, or print.
5. Catalog every produced file with `GEN`, platform/placement, dimensions, copy source, image source, rights status, safety status, fact status, CTA/destination, owner, and notes.
